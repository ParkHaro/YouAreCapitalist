## 1. 투자 루프 개요

투자 루프는 YouAreCapitalist의 주요 경제 엔진으로, 플레이어가 금융 시장과 상호작용하고 자본을 증식시키는 핵심 메커니즘을 나타냅니다. 이 루프는 플레이어가 진행함에 따라 직접적인 거래에서 완전 자동화된 자본 배분으로 진화합니다.

### 1.1 루프 플로우 다이어그램

```
💰 자본 배분
    ↓ (결정: 가용 자본을 어디에 투자할 것인가)
📊 시장 분석
    ├── 기술적 분석 (차트, 패턴, 지표)
    ├── 펀더멘털 분석 (기업 재무, 경제학)
    ├── 심리 분석 (뉴스, 소셜 미디어, 시장 분위기)
    └── AI 어드바이저 입력 (알고리즘 추천)
    ↓ (결정: 어떤 자산을 타겟할 것인가)
🎯 투자 결정
    ├── 자산 선택 (주식, 채권, 파생상품, 대체투자)
    ├── 포지션 사이즈 (얼마나 투자할 것인가)
    ├── 위험 관리 (손절매, 헤징)
    └── 타임라인 설정 (단기, 중기, 장기)
    ↓ (실행: 주문 배치, 포지션 관리)
📈 포지션 관리
    ├── 성과 모니터링 (실시간 손익 추적)
    ├── 리밸런싱 트리거 (자동 조정)
    ├── 출구 전략 실행 (이익 실현, 손실 제한)
    └── 최적화 (세금 효율성, 비용 절감)
    ↓ (결과: 이익/손실 실현)
💵 자본 증가/손실
    ├── 재투자 결정 (복리 vs 인출)
    ├── 레버리지 조정 (위험 선호도 변화)
    ├── 포트폴리오 다각화 (위험 분산)
    └── 전략 진화 (결과로부터 학습)
    ↓ (수정된 자본 베이스로 시작점 복귀)
```

## 2. 시장 분석 시스템

### 2.1 기술적 분석 엔진

#### 가격 패턴 인식
- **차트 패턴**: 헤드 앤 숄더, 삼각형, 채널, 플래그
- **캔들스틱 패턴**: 도지, 해머, 잉걸핑, 슈팅스타
- **지지/저항**: 과거 가격 행동 기반 동적 레벨
- **트렌드 분석**: 이동평균, 추세선, 모멘텀 지표

#### 기술 지표
```yaml
모멘텀 지표:
  - RSI (상대강도지수)
  - MACD (이동평균 수렴확산)
  - 스토캐스틱 오실레이터
  - 윌리엄스 %R

추세 지표:
  - 이동평균 (단순, 지수, 가중)
  - 볼린저 밴드
  - 패러볼릭 SAR
  - 일목 균형표

거래량 지표:
  - OBV (온밸런스 거래량)
  - VWAP (거래량 가중 평균가)
  - 누적/분산 라인
  - 차이킨 머니 플로우

변동성 지표:
  - ATR (평균 실제 범위)
  - 변동성 지수 (VIX 등가)
  - 표준 편차
  - 돈치안 채널
```

#### 알고리즘 스코링 시스템
- **신호 강도**: 각 지표별 0-100 척도
- **일치도**: 다중 지표 합의 가중치
- **신뢰성**: 지표별 과거 정확도 추적
- **시장 상황**: 강세/약세/횡보 시장 조정

### 2.2 펀더멘털 분석 프레임워크

#### 기업 수준 분석
```yaml
재무 건전성:
  - 매출 성장: 전년 동기, 전분기 트렌드
  - 수익성: 총이익률/영업이익률/순이익률
  - 부채 관리: 부채비율, 이자보상배수
  - 현금 흐름: 영업/잉여 현금 흐름 창출
  - 수익률 지표: ROE, ROA, ROIC

밸류에이션 지표:
  - 가격 비율: P/E, P/B, P/S, PEG
  - 기업 가치: EV/EBITDA, EV/Sales
  - 배당 수익률: 현재 및 예상
  - 내재 가치: DCF, DDM 계산

경쟁 포지션:
  - 시장 점유율: 업계 내 위치
  - 해자 강도: 경쟁 우위
  - 경영진 품질: 리더십 효과성
  - 혁신 파이프라인: R&D 투자, 특허
```

#### 거시경제 분석
```yaml
경제 지표:
  - GDP 성장: 국가 경제 건전성
  - 인플레이션: CPI, PPI 트렌드
  - 금리: 중앙은행 정책
  - 고용: 실업률, 일자리 창출

시장 조건:
  - 섹터 로테이션: 업종 성과 사이클
  - 위험 선호: 안전자산 vs 위험자산
  - 유동성: 통화 공급, 신용 조건
  - 지정학: 무역, 분쟁, 제재

통화 및 국제:
  - 환율: 통화 강도 영향
  - 국제 무역: 수출입 동향
  - 글로벌 시장: 상관관계 분석
  - 원자재 가격: 자원 비용 영향
```

### 2.3 심리 분석 시스템

#### 뉴스 임팩트 엔진
- **소스 신뢰성**: 출처 신뢰도별 뉴스 가중치
- **심리 스코링**: 자연어 처리를 통한 분위기 분석
- **이벤트 분류**: 실적, M&A, 규제, 스캔들
- **시장 반응 예측**: 과거 반응 패턴

#### 소셜 미디어 통합
- **인플루언서 추적**: 금융 분야 핵심 오피니언 리더
- **소매 심리**: 소셜 미디어 버즈 분석
- **바이럴 트렌드**: 밈 주식 현상 시뮬레이션
- **역행 신호**: 군중 심리 반전

#### 시장 심리 지표
- **공포 & 탐욕 지수**: 시장 감정 측정
- **옵션 플로우**: 풋/콜 비율, 이상 활동
- **내부자 거래**: 기업 내부자 매수/매도 패턴
- **애널리스트 업그레이드/다운그레이드**: 전문가 심리 변화

## 3. 투자 결정 프레임워크

### 3.1 자산 분류 시스템

#### 전통적 증권
```yaml
주식:
  대형주: 안정적 기업, 안정적 수익
  중형주: 성장 잠재력, 중간 위험
  소형주: 높은 성장, 높은 변동성
  초소형주: 투기적, 극도의 변동성

채권:
  국채: 무위험 수익률 벤치마크
  회사채: 신용 위험 vs 수익률
  지방채: 세금 혜택
  해외채: 통화 노출

우선주:
  배당 우선권: 소득 중심
  전환 기능: 주식 상승 잠재력
  신용 품질: 기업 안정성
```

#### 대체 투자
```yaml
부동산:
  REITs: 유동적 부동산 노출
  직접 부동산: 비유동적, 레버리지 기회
  부동산 개발: 고위험/고수익

원자재:
  귀금속: 금, 은 인플레이션 헤지
  에너지: 석유, 가스 공급/수요 역학
  농업: 식품 가격 인플레이션 노출
  산업 금속: 경제 사이클 민감성

사모펀드:
  바이아웃: 성숙 기업 개선
  벤처캐피털: 초기 단계 기술
  성장 자본: 확장 자금 조달
  부실 투자: 턴어라운드 기회
```

#### 파생상품 & 구조화 상품
```yaml
옵션:
  콜 옵션: 강세 투기, 레버리지
  풋 옵션: 약세 투기, 헤징
  복잡한 전략: 스프레드, 스트래들, 칼라

선물:
  지수 선물: 시장 노출, 헤징
  원자재 선물: 가격 투기/헤징
  통화 선물: 환율 플레이

구조화 상품:
  시장 연계 CD: 원금 보호
  주식 연계 채권: 맞춤형 노출
  합성 상품: 수익률 엔지니어링
```

### 3.2 포지션 사이징 알고리즘

#### 위험 기반 사이징
```python
# 켈리 기준 구현
def kelly_criterion(win_probability, avg_win, avg_loss):
    if avg_loss == 0:
        return 0
    win_loss_ratio = avg_win / avg_loss
    kelly_percentage = win_probability - ((1 - win_probability) / win_loss_ratio)
    return max(0, min(kelly_percentage, 0.25))  # 포지션당 25% 상한

# 위험 균형 접근법
def risk_parity_sizing(portfolio_volatility_target, asset_volatility, correlation_matrix):
    # 포지션 간 동등한 위험 기여
    risk_budget = portfolio_volatility_target / len(assets)
    position_size = risk_budget / (asset_volatility * correlation_adjustment)
    return position_size

# 시장 조건 기반 동적 사이징
def adaptive_position_sizing(base_size, market_volatility, account_size, drawdown_level):
    volatility_adjustment = 1 / (1 + market_volatility)
    drawdown_adjustment = 1 - (drawdown_level * 0.5)
    size_modifier = volatility_adjustment * drawdown_adjustment
    return base_size * size_modifier
```

#### 자본 배분 규칙
- **단일 포지션 최대**: 포트폴리오의 10% (초기) → 25% (후기)
- **섹터 집중**: 단일 섹터 30% 이하
- **상관관계 제한**: 높은 상관관계 포지션 회피
- **유동성 요구사항**: 5-15% 현금 버퍼 유지

### 3.3 위험 관리 프레임워크

#### 손절매 전략
```yaml
고정 비율:
  보수적: 진입가 대비 5% 하락
  중간: 진입가 대비 10% 하락
  공격적: 진입가 대비 15% 하락

기술적 손절매:
  지지선: 주요 지지선 하회
  이동평균: 20/50/200일 선 하회
  변동성 기반: ATR 배수 손절매

시간 기반 손절매:
  실적 윈도우: 실적 발표 전 청산
  경제 이벤트: 연준 회의, GDP 발표
  포지션 기간: X일 후 자동 검토
```

#### 헤징 메커니즘
```yaml
포트폴리오 헤징:
  지수 풋: 시장 폭락 보호
  VIX 콜: 변동성 급등 보험
  통화 헤징: 해외 투자 보호

포지션 헤징:
  보호적 풋: 개별 주식 보호
  칼라 전략: 상승/하락 한계
  페어 트레이딩: 관련 주식 롱/숏

동적 헤징:
  델타 헤징: 옵션 포트폴리오 중립화
  감마 헤징: 곡률 위험 관리
  베가 헤징: 변동성 위험 통제
```

## 4. 자동화 시스템 설계

### 4.1 자동화 레벨

#### 레벨 0: 수동 거래
```yaml
플레이어 통제: 100%
특징:
  - 모든 거래에 명시적 승인 필요
  - 실시간 시장 모니터링 필수
  - 높은 학습 곡선, 최대 참여도
  - 적합한 단계: 튜토리얼, 초기 게임, 학습 단계

기능:
  - 주문 입력 확인 대화상자
  - 실시간 손익 알림
  - 뉴스 알림 시스템
  - 기본 차트 도구
```

#### 레벨 1: 보조 거래
```yaml
플레이어 통제: 80%
특징:
  - AI가 근거와 함께 추천 제공
  - 플레이어가 최종 결정
  - 위험 경고 및 포지션 사이징 제안
  - 적합한 단계: 초기-중기 게임 전환

기능:
  - 신뢰도 점수와 함께 신호 알림
  - 자동 손절매 배치
  - 포지션 사이징 추천
  - 위험 지표 대시보드
```

#### 레벨 2: 알고리즘 거래
```yaml
플레이어 통제: 50%
특징:
  - 사전 정의된 규칙이 자동 실행
  - 플레이어가 매개변수와 제약 설정
  - 주요 결정에 개입 가능
  - 적합한 단계: 중기 게임 포트폴리오 관리

기능:
  - 규칙 기반 전략 배포
  - 자동 리밸런싱
  - 위험 기반 포지션 스케일링
  - 성과 기여도 분석
```

#### 레벨 3: AI 포트폴리오 관리
```yaml
플레이어 통제: 20%
특징:
  - 머신러닝이 의사결정 최적화
  - 플레이어가 고수준 목표 제공
  - 시장 조건에 자동 적응
  - 적합한 단계: 후기 게임 자본 배분

기능:
  - 다인자 모델 최적화
  - 동적 전략 전환
  - 교차 자산 차익거래
  - 대체 데이터 통합
```

#### 레벨 4: 자율 자본 배분
```yaml
플레이어 통제: 5%
특징:
  - 완전 자율 투자 결정
  - 플레이어는 위험 허용도만 설정
  - 강화학습을 통한 자기 개선
  - 적합한 단계: 엔드 게임 수동 소득

기능:
  - 비지도 학습 알고리즘
  - 다중 시간대 최적화
  - 교차 시장 기회 스캐닝
  - 시스템 위험 모니터링
```

### 4.2 알고리즘 개발 진행

#### 전략 템플릿 시스템
```yaml
템플릿 카테고리:
  모멘텀: 추세 추종 전략
  평균 회귀: 역행 접근법
  가치: 펀더멘털 분석 기반
  성장: 성장주 식별
  소득: 배당/수익률 중심
  차익거래: 가격 불균형 활용

커스터마이제이션 옵션:
  - 진입/청산 기준 수정
  - 위험 매개변수 조정
  - 시간대 선택
  - 자산 유니버스 정의
  - 상관관계 제약
```
